Layihə haqqında

Sadəlik, nəzarət və fərdiləşdirmə.

TUXIXI Terminal gündəlik terminal işini daha şəxsi və rahat etmək üçün hazırlanmış masaüstü layihəsidir. O, sistemdəki Bash qabığından istifadə edir; məqsədi yeni shell yaratmaq deyil, terminal təcrübəsini öz interfeysi və alətləri ilə təqdim etməkdir.

Texnologiyalar

Python · GTK 4 · VTE · PyGObject · Bash

  • Linux masaüstü mühiti üçün hazırlanıb
  • GTK4 pəncərə interfeysi və VTE terminal sahəsi
  • Açıq mənbəli, yoxlanıla bilən kod
  • Tənzimləmələr istifadəçi konfiqurasiyasında saxlanılır
