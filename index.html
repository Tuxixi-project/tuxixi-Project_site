TUXIXI.

TUXIXI is a terminal emulator built with Python, GTK4 and VTE. It offers a clean interface for everyday work, with useful shortcuts and customizable colors.

About

TUXIXI is a simple terminal emulator for Linux. It uses your system shell instead of creating a new one.

Features

  • Clean, simple interface
  • GTK4 and VTE
  • Customizable color themes
  • Keyboard shortcuts
  • Aliases and settings
  • Open source
